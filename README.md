# 🌌 Raga-Vibe: 10 Digital Dimensions

Welcome to **Raga-Vibe**, a curated collection of 10 unique, interactive, and fully responsive web experiments. Built entirely from scratch using pure HTML, CSS, and JavaScript — zero dependencies, zero frameworks, just raw creative code.

🔗 **Live Demo:** [GitHub Pages Link Here] *(Add your link once deployed!)*

---

## ✨ The 10 Dimensions

1. 🎵 **Raga-Vibe** — Ambient music visualizer with a working audio oscillator.
2. 🌌 **Cosmic Drift** — Interactive 3D starfield. Click to warp, move to steer.
3. 🕹️ **Neon Snake** — A retro arcade snake game with glowing cyberpunk aesthetics.
4. 🎨 **Generative Flow** — Procedural flow-field art. Every reload is a new masterpiece.
5. 🧘 **Zen Timer** — A 4-7-8 breathing meditation guide with an expanding visual pulse.
6. 💾 **Cyber Terminal** — A fake hacker terminal with typing effects and hidden commands.
7. 🌦️ **Mood Weather** — Switch between rain, snow, sun, and autumn with animated particles.
8. ✒️ **Poetry Machine** — An algorithmic haiku/poem generator.
9. 🎲 **3D Cube Gallery** — A fully draggable, touch-enabled 3D CSS cube.
10. 🫧 **Liquid Glass** — A modern glassmorphism landing page with morphing blobs.

---

## 📱 Mobile Compatibility

Every single experiment is **100% mobile-responsive**. 
- Touch controls for the Snake game.
- Swipe/drag support for the 3D Cube.
- Fluid typography and scalable canvases for any screen size.
- A collapsible hamburger menu for easy navigation.

---

## 🚀 How to Run

Since there are no dependencies, running this is incredibly simple:

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser (Chrome, Firefox, Safari, Edge).
3. That's it! No `npm install`, no build steps. 

*Tip: For the best experience viewing the Cosmic Drift and Flow Field, use a desktop browser, but everything works beautifully on mobile too!*
